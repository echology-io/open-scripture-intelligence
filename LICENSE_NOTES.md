## Copyrighted Translations

Modern translations such as ESV, NIV, NASB, and NLT are **copyrighted** and are **not included** in this repository.

If you wish to use a copyrighted translation with OSI:

- Check the publisher's permission guidelines
- Use the publisher's official API where available
- Respect quotation limits (e.g., Crossway's ESV permits up to 500 verses for certain uses)
- Do not redistribute copyrighted text in derivative datasets
